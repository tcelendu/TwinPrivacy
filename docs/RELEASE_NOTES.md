# Public repository release notes — v0.6.1

This release packages TwinPrivacy's existing reproducible research software
for public source-code review and replication.

## Included

- Python 3.11+ disclosure-analysis engine and receipt-verification tool
- Patient-facing disclosure statement and research validation HTML report
- Fully documented, seeded 512-record generated clinical dataset
- Reproducible 4,096-event validation with 8,192 reference comparisons
- Automated test suite and single-command regeneration
- GitHub Actions reproducibility workflow for Python 3.11–3.13
- MIT source licence, CC0 data licence and CC BY 4.0 report licence

## Scope

Numerical validation is performed against the declared model; the dataset
is generated for computational assessment. Independent clinical validation,
real-world log completeness, and a new formal privacy guarantee are not
claimed. Publication on GitHub is a separate action that requires an account.
